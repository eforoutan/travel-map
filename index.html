About

Cities I've Been

An interactive world map for pinning everywhere you've wandered. Search a city or right-click the map to drop a pin, label it, and it saves straight to your Supabase PostGIS database — live across every device.

Leaflet.js
Open-source web-mapping engine handling the map, markers, and pan/zoom. No API key needed.
Esri-style light canvas
CARTO Positron raster tiles over OpenStreetMap data — a clean neutral basemap.
OpenStreetMap · Nominatim
Free worldwide geocoding & reverse-geocoding for city search and map clicks.
Supabase PostGIS
Pins live in a spatial points table. Every device reads the same rows in real time; a trigger keeps the geometry in sync.
Row Level Security
Anyone can view the map; only a signed-in owner can add, edit, or delete pins.
Vanilla JS · HTML · CSS
A single self-contained index.html. No frameworks, no build step.

A single index.html — drop it on GitHub Pages and it just works.

Sign in to edit

Anyone can view this map. To add, edit, or delete pins you sign in with the email registered as the map owner in Supabase. We'll email you a one-time magic link — no password.

How editing is protected

The map reads through Supabase's public anon key, which is safe to ship in the page. Writing is gated by Row Level Security: only an authenticated session may insert, update, or delete rows.

If you try to edit while signed out, the change is refused by the database and you'll be prompted to sign in.
